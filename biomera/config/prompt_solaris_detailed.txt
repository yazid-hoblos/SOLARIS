MODULE 1: PATHWAY PROFILER (solaris pathway_profiler)
═══════════════════════════════════════════════════════════════════════

PURPOSE: Analyze metabolic pathway coverage in genomes using EC-based profiling

SUBCOMMANDS:

1. workflow - Complete automated pipeline
   Usage: solaris pathway_profiler workflow --pathway <id> --genome <file> --pfam-db <path> [options]
   
   Required:
   --pathway: KEGG pathway ID (e.g., map00720) or --module for KEGG module (e.g., M00376)
   --genome: Target genome FASTA file (.faa)
   --pfam-db: Path to Pfam-A.hmm database
   
   Optional:
   --output-dir: Output directory (default: pathway_analysis_results)
   --evalue: E-value threshold (default: 1e-5, use 1e-3 for sensitive search)
   --visualize: Generate KEGG pathway map
   --plot: Generate descriptive plots
   --headless: Run without browser (for servers)
   --interactive: Enable interactive pathway search
   
   Output Files:
   - ec_results.csv: Main results with FULLY_FOUND/PARTIALLY_FOUND/NOT_FOUND status
   - ec_summary.txt: Human-readable summary
   - ec_pfam_mapping.txt: EC to Pfam domain mappings
   - selected_pfam.hmm: Custom HMM profiles
   - hits_table.txt: Raw HMM search results
   - detailed_hits.csv: Comprehensive hit information

2. extract-ec - Extract EC numbers from KEGG
   Usage: solaris pathway_profiler extract-ec --pathway <id> --output <file>
   OR: solaris pathway_profiler extract-ec --module <id> --output <file>
   
   Examples:
   solaris pathway_profiler extract-ec --pathway map00720 --output ec_3hp.txt
   solaris pathway_profiler extract-ec --module M00376 --output ec_m00376.txt

3. get-profiles - Extract HMM profiles from Pfam
   Usage: solaris pathway_profiler get-profiles --input <ec_pfam_file> --pfam-db <path> --output <hmm_file>
   
   Process: Queries UniProt → Maps to Pfam → Extracts HMM profiles

4. search - Search genome with HMMs
   Usage: solaris pathway_profiler search --hmm <file> --genome <file> --output <file> --evalue <threshold>
   
   Uses pyhmmer for fast parallel searching

5. analyze - Analyze results and calculate coverage
   Usage: solaris pathway_profiler analyze --hits <file> --input <ec_pfam> --hmm <file> --output-dir <dir>

6. visualize - Generate KEGG pathway visualization
   Usage: solaris pathway_profiler visualize --results <csv> --pathway <id> [--headless]

COMMON PATHWAYS:
- map00720: 3-Hydroxypropanoate bi-cycle (3HP/4HB carbon fixation)
- map00190: Oxidative phosphorylation
- map00710: Calvin cycle (CBB carbon fixation)
- M00376: 3-Hydroxypropionate bi-cycle (module)

RESULT INTERPRETATION:
- 🟢 FULLY_FOUND: All required Pfam domains detected (high confidence)
- 🟡 PARTIALLY_FOUND: Some domains detected (manual inspection recommended)
- 🔴 NOT_FOUND: No required domains (enzyme likely absent)

MODULE 2: PANGENOMIC ANALYZER (solaris pangenomic_analyzer)
═══════════════════════════════════════════════════════════════════════

PURPOSE: Compare pathway completeness across multiple strains for chassis selection

PREREQUISITES (from pathway_profiler):
1. EC-Pfam mapping file (pfam_ids.txt) from extract-ec
2. HMM profiles (selected_pfam.hmm) from get-profiles
3. EC numbers list (ec_numbers.txt)

SUBCOMMANDS:

1. complete - Full pangenomic analysis workflow
   Usage: solaris pangenomic_analyzer complete --genomes-dir <dir> --hmm-file <hmm> [options]
   
   Required:
   --genomes-dir: Directory with genome FASTA files (.faa)
   --hmm-file: HMM profiles from pathway_profiler
   
   Optional:
   --ec-pfam-mapping: EC-Pfam mapping file (pfam_ids.txt)
   --target-ecs: Target EC numbers file
   --output-dir: Results directory (default: results)
   --plot-dir: Plots directory (default: plots)
   --parallel: Enable parallel processing
   --max-workers: Number of parallel workers (default: 4)
   --evalue: E-value threshold (default: 1e-5)
   --plot: Generate visualizations
   --similarity-analysis: Calculate strain similarities
   
   Output Files:
   - comparison_matrix.csv: Strain × EC presence/absence matrix
   - strain_rankings.csv: Completeness rankings with metrics
   - results/batch/*.csv: Individual strain results
   - strain_similarity.csv: Pairwise similarity (if requested)
   
   Plots (if --plot):
   - comparison_heatmap.png: EC presence/absence heatmap
   - completeness_distribution.png: Score distributions
   - ec_frequency_plot.png: EC frequency across strains
   - top_strains_plot.png: Top performers
   - strain_dendrogram.png: Hierarchical clustering
   - clustered_heatmap.png: Clustered data view

2. hmm-analysis - HMM search only
   Usage: solaris pangenomic_analyzer hmm-analysis --genomes-dir <dir> --hmm-file <hmm> [options]
   
   Runs HMM searches on all strains, creates individual result files

3. pathway-analysis - Analyze existing HMM results
   Usage: solaris pangenomic_analyzer pathway-analysis --results-dir <dir> [options]
   
   Analyzes pre-computed HMM results, generates rankings and plots

PERFORMANCE:
- Successfully tested with 122+ strains
- Parallel processing recommended for large datasets
- Handles adaptive visualization for >50 strains

ACCESSING GENOMES:
Use pangenomic_analyzer/access_genomes.py to download genomes for target species

MODULE 3: COMPATIBILITY PREDICTOR (solaris compatibility_predictor)
═══════════════════════════════════════════════════════════════════════

PURPOSE: Identify organisms suitable for heterologous pathway implementation based on genetic capability and physiological compatibility

WORKFLOW:
1. Extract genes/organisms from KEGG → kegg command
2. Filter by physiological criteria → bacdive command
3. Match and validate organisms → match command

SUBCOMMANDS:

1. kegg - Query KEGG for EC-associated organisms
   Usage: solaris compatibility_predictor kegg --ec-file <file> [options]
   
   Required:
   --ec-file: File with EC numbers (one per line)
   
   Optional:
   --output: Output JSON file (default: kegg_results.json)
   --max-species: Max species per EC (default: 3)
   
   Output:
   - JSON with EC → genes → organisms mapping
   - TXT file with identified species names

2. bacdive - Filter organisms by physiological criteria
   Usage: solaris compatibility_predictor bacdive --email <email> --taxonomy <term> [options]
   
   Required:
   --email: Your email address
   --taxonomy: Taxonomy search term (e.g., "Synechococcus", "Cyanobacteria")
   
   Optional:
   --password: BacDive password (will prompt if not provided)
   --temp-min: Minimum temperature (default: 20°C)
   --temp-max: Maximum temperature (default: 45°C)
   --temp-type: 'optimum', 'minimum', or 'maximum' (default: optimum)
   --max-strains: Max strains to process (default: 200)
   --output: Output prefix (default: taxonomy name)
   
   Filters Applied:
   - Aerobic oxygen tolerance
   - Temperature range
   
   Output:
   - {taxonomy}_aerobic.json: Aerobic organisms
   - {taxonomy}_temperature.json: Temperature-filtered organisms
   
   NOTE: Requires BacDive account (register at https://api.bacdive.dsmz.de/)

3. match - Match organisms between KEGG and BacDive
   Usage: solaris compatibility_predictor match --email <email> [options]
   
   Required:
   --email: Email for NCBI API access
   
   Optional:
   --kegg-file: KEGG results JSON (default: kegg_results.json)
   --bacdive-file: BacDive results JSON (default: mesophiles.json)
   --output-json: Output JSON (default: taxid_matches.json)
   --output-txt: Output text (default: taxid_matched_species.txt)
   
   Process:
   1. Load KEGG and BacDive data
   2. Extract species names
   3. Validate via NCBI taxonomy
   4. Cross-reference taxonomy IDs
   5. Generate match reports
   
   Output:
   - JSON with matched organisms and metadata
   - TXT report with species details

COMPLETE WORKFLOW EXAMPLE:
# Step 1: Get organisms with target enzymes
solaris compatibility_predictor kegg --ec-file pyruvate_ecs.txt --output pyruvate_kegg.json

# Step 2: Filter cyanobacteria by growth conditions
solaris compatibility_predictor bacdive --email your@email.com --taxonomy Synechococcus --temp-min 25 --temp-max 35 --output marine_cyano

# Step 3: Find compatible organisms
solaris compatibility_predictor match --email your@email.com --kegg-file pyruvate_kegg.json --bacdive-file marine_cyano_aerobic.json --output-json compatible.json
